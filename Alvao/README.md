# **Unofficial** Alvao API Definition

Generated class library of the ALVAO API for developing ALVAO custom applications with IDE and AI assistant support.

> [!CAUTION]
> This project is not affiliated with ALVAO s.r.o.
> All class files were generated from the publicly available documentation at <https://doc.alvao.com/en/26/alvao-api/api/Alvao.API.AI.html>.
> Correctness of the generated files is not guaranteed.

The package contains definitions only; method bodies throw `NotImplementedException`. The ALVAO database schema (tables, column types, foreign keys) is included as `DATABASE.md` in the package root.

Generator project and examples are available at [Ash258/AlvaoApiDefinition](https://github.com/Ash258/AlvaoApiDefinition).
